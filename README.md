# AI Cognitive Gaming & Memory Assistance Platform

An AI-powered cognitive gaming platform for elderly dementia patients in North Eastern Region (NER).

## Tech Stack
- Frontend: React + Vite + Tailwind CSS
- Backend: FastAPI (Python)
- Database: PostgreSQL
- AI: Scikit-learn, XGBoost
- Deployment: Docker

## How to Run
1. Install Docker.
2. Run `docker-compose up --build`
3. Access frontend at http://localhost:3000 and backend at http://localhost:8000
